## 预设验收矩阵

在目标 RTX A6000 上以 32K/64K/128K × B4/B16 × 连续/128-token 块打散/逐 token 打散为共同条件。Full 共 18 格，Refinement 增加 M=3072/8192 两档，共 36 格。优先使用层 36、步 2、请求偏移 8，输入捕获不足时明确报告替代采集与实际层步。开发调优与验收条件分开。每格只比较相同输入、输出合同和执行边界。候选已经可用时的精排延迟与从原始 hidden state 开始的完整 Indexer 延迟单独标记。

分母取各格最快通过正确性校验的既有实现，包括适用的上一轮无损优化。单格加速 = 基线延迟/新路径延迟。冻结策略的各格比值先对数等权平均再取指数。分别列 18 和 36 格结果，整体同时给出两类各占一半和全部格子等权的几何平均数。逐点最优仅作事后上限。正确性检查候选集合、严格高分遗漏、边界同分；近似模块另报相对原生全历史的集合误差与模型任务分数。以实际服务部署范围解释端到端结果。
